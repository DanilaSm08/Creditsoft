# CreditSoft

Учебное веб-приложение оценки кредитоспособности. Django, PostgreSQL,
HTML/CSS/JavaScript, Bootstrap, Docker Compose. Реальные банки и БКИ не вызываются.

Лабораторные: 5 — Git и CI, 6 — прототип, 7 — автоматические тесты,
8 — завершенная система и отчет о релизе.

Инструкции запуска и доказательства выполнения дополняются по мере этапов.
