# Прототип v0.1.0 — ЛР6

Цель: проверить сценарий «регистрация → вход → личная и финансовая анкета → проверка → сохранение → повторное открытие → исправление → выход» до реализации расчётного контура.

Реализованы PR-01 и CR-01.1–CR-04.3 (12 функциональных задач, 58 плановых часов; PR-01 — 4 часа). Проверяемые результаты: 37 автоматических тестов, в том числе один полный сценарий Chromium; отдельные снимки настольного и мобильного интерфейсов. Скриншоты сняты с выполняющегося приложения на синтетических данных.

В прототип не входят CR-05–CR-08: расчёт нагрузки и рейтинга, каталог и подбор предложений, итоговый экран. Эти функции относятся к следующему инкременту. Прототип является работающим вертикальным срезом, а не макетом со статическими результатами.

Выбор Django, серверных шаблонов и Bootstrap подтверждён: форма, ORM, аутентификация и CSRF работают совместно; отдельный SPA и микросервисы не нужны. Валидация выполняется сервером, обе части анкеты сохраняются одной транзакцией. Playwright проверяет реальный браузер и отсутствие горизонтального переполнения при ширине 390 px.

Оценки из ЛР2–3 относятся к самостоятельной разработке в течение семестра. Фактическое время этой работы измеряется журналом tools/tasklog.py как длительность этапа с автоматизированной помощью; сравнивать его с индивидуальными трудозатратами без оговорки нельзя. По отдельным задачам время не распределялось задним числом. Проверка преподавателем не проводилась и не имитируется.

Ограничения: учебная модель, только синтетические персональные данные; SQLite применяется для быстрого локального прогона, PostgreSQL проверяется при контейнерном развёртывании. Внешний GitHub не доступен через текущую авторизацию; фактический репозиторий и CI находятся в локальном Gitea.
